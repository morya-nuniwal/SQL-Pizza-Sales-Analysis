# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview

This project analyzes pizza sales data using SQL and MySQL Workbench.

The objective is to explore sales performance, customer orders, revenue, and product-level trends using SQL queries.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 🎯 Objectives

- Analyze overall pizza sales
- Identify best-selling pizzas
- Analyze revenue generated
- Identify sales trends
- Understand customer ordering patterns
- Practice SQL querying and data analysis

## 📊 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOIN
- CASE Statements
- Subqueries

## 📁 Project Files

`pizza_sales.sql` — Contains the SQL queries used for the analysis.
